Labelled text field. Square-ish 6px corners (never pill) with a rose focus ring.

```jsx
<Input label="Seu e-mail" type="email" placeholder="email@exemplo.com" />
<Input label="Nome" helper="Como devemos te chamar?" />
<Input label="Senha" type="password" error="Mínimo de 8 caracteres" />
```

Pass `iconLeft` for a leading glyph. `error` turns the border and message rose.
